# Ядро стенда курса «Программирование в режиме ядра»

Сборка ядра Linux, на котором автоматически проверяются лабораторные работы курса.
Модуль собирается под это ядро и загружается в него внутри QEMU, поэтому результат
проверки не зависит от того, какое ядро стоит на машине студента или на раннере GitHub.

| Вариант | Версия ядра | Где используется |
|---|---|---|
| `stand` | `6.8.12-kmc` | лабы 1, 2, 5, 6 |
| `debug` | `6.8.12-kmc-debug` | лабы 3, 4, 7, 8: KASAN, UBSAN, lockdep, kmemleak, отладочная информация |

Конфигурация — `x86_64_defconfig` плюс фрагменты из `configs/`. Скрипт `build.sh`
проверяет, что каждая опция из фрагментов действительно попала в итоговый `.config`.

## Релиз

Тег вида `kmc-6.8.12-N` запускает сборку обоих вариантов в GitHub Actions и публикует
релиз. Архив `kmc-<вариант>-6.8.12.tar.xz` содержит:

- `vmlinuz` — образ ядра для `qemu-system-x86_64 -kernel`;
- `build/` — дерево для сборки внешних модулей: `make -C build M=$PWD`;
- `config`, `System.map`, `release`.

Скачивать вручную не нужно: это делает `common/fetch_kernel.py` в репозитории лабораторной.

## Собрать локально

```bash
./build.sh debug out/      # нужны flex, bison, libelf-dev, libssl-dev, dpkg-dev
```
